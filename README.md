# Gem System Page

Página de presentación de [`@gem-org/gem-system`](https://www.npmjs.com/package/@gem-org/gem-system), con showcase de implementación.

## Stack

- Vite + React 19 + TypeScript
- React Router
- `@gem-org/gem-system`
- `@gem-org/gemffects`
- `@gem-org/gemsitions`

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Rutas

- `/` — Home de presentación (estilo landing)
- `/showcase` — Demos live por sección (Storybook-aligned)
- `/getting-started`, `/foundations/*`, `/components/*` — docs de uso
